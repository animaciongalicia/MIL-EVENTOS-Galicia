# Mil Eventos Galicia

Web corporativa de [Mil Eventos Galicia](https://mileventosgalicia.com) — agencia de eventos de empresa en Galicia (team building, incentivos, jornadas outdoor, congresos y convenciones), localización de espacios, traslados, alojamiento, y una línea secundaria de celebraciones sociales.

Lee `CLAUDE.md` antes de tocar cualquier página, componente o texto. El mapa de rutas de referencia está en `sitemap-definitivo.md`.

## Stack

- [Next.js](https://nextjs.org/) (App Router) + React + TypeScript
- [Tailwind CSS](https://tailwindcss.com/)
- Contenido en archivos (`.mdx` para blog, `.ts` para datos de ejemplos) — sin CMS ni base de datos en esta fase
- Despliegue en [Vercel](https://vercel.com/)

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
